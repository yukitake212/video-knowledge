# video-knowledge

AI映像制作の知見リポジトリ。案件の作業文書は別リポジトリ（video-projects）。

## どこから読むか

**初めてなら `ONBOARDING.md`。** 読む順序、制作の流れ、判断の分岐点、記録のしかたが
1枚にまとまっている。**このリポジトリは約9,800行あるので、全部読まない前提で作ってある。**

そのうえで、**目的が3つあって、入口が違う。**

| やりたいこと | 読む |
|---|---|
| **制作で使う**（プロンプトを書く、構成を組む、生成の失敗を直す） | `skill/SKILL.md` |
| **リポジトリに書き込む**（知見を足す、置き場所を決める） | `CLAUDE.md` |
| **知見を持ち込む／他のLLMに書かせる** | `DIFF-FORMAT.md` |
| **ChatGPT で使う／書かせる** | `CHATGPT.md` |

`skill/SKILL.md` は**工程を判定してから読むファイルを絞る**作りになっている。
**`principles/` を頭から読む必要はない。** 初めてなら「使い方」節から。

## 構成

### ディレクトリ

- `principles/` — モデル非依存の原則。どのプラットフォームでも効く書き方の芯。うち `workflow.md`（発想と制作の工程）は**プロンプトを書く前に読む**
- `models/` — ベースモデルの知識（公式仕様・プロンプト式・生成モード・ハード上限）
- `platforms/` — ホスト別の仕様（UI・上限・書き換え・契約・料金）。**必ず確認日を書く**。仕様は変わる
- `templates/` — 埋めて使う型。ハウススタイルブロックはここ
- `genres/` — ジャンル別の知見。principles/ に混ざったジャンル固有の内容は順次こちらへ移す
- `skill/` — **制作でこのリポジトリを使うときの入口。** 工程の判定、工程ごとに読む／読まない
  ファイル、症状からの索引。Claude Skill と ChatGPT ナレッジのビルド元でもある

`principles/` `platforms/` `templates/` `models/` `genres/` にはそれぞれ `README.md` がある。
**ディレクトリREADMEは一覧と一行説明だけ。「どの工程で読むか」の判断は `skill/SKILL.md` に
一本化してある**（二重に持つと片方だけ古くなる）。**この5つは配布物には入らない。**

### ルート直下のファイル

- `CLAUDE.md` — このリポジトリで作業するときの規則（書き方のルール、置いてはいけないもの、public / private の判断）
- `OPERATIONS.md` — 制作事業の運用（棚卸し・リスク管理・案件選別・クライアントとのやりとり）
- `DIFF-FORMAT.md` — 知見を持ち込むための差分ファイルの型。**他のLLMへ渡す指示文もここ**
- `CHANGELOG.md` — 覆った知見と、覆った理由
- `ONBOARDING.md` — **新しく入る人向け。** 学習の順序／制作の流れ／判断の分岐点／記録の流れ
- `CHATGPT.md` — **ChatGPT 側の設定と注意。** メモリに入れる文面、Claude 側との構造の差、
  書かせたときの引用の確かめ方
- `build-skill.sh` — `skill/SKILL.md` と各ディレクトリから、Claude Skill（zip）・
  Claude Code 用ローカル版・ChatGPT 用ナレッジをビルドする。
  **参照切れ・マーカーの残留・フラット化での名前衝突を毎回検査する**

生プロンプトの原文はこのリポジトリには置かない。**video-corpus（private）** にある。

## 書き方のルール

1. 各項目に**出所と時期**を書く。自分たちで検証したのか、他人の公開プロンプトから読んだのか、推測なのか
2. **プラットフォーム固有の制約を法則として書かない**。過去に「ショット生成は4秒以上」をH3の制約と気づかずに普遍則として記録し、全カットの設計を縛った
3. 「これが正解で確定」という態度は、新しいものが見えてきたときの障害になる。探索姿勢と、既に得た知見を活かす姿勢を両立させる
4. `principles/` に書いた項目の末尾には、根拠になった原文を `(corpus/xxx)` の形でファイル名だけ書く。実体は video-corpus 側にある

## 入れないもの

- バイナリ（動画・画像・PDF）。素材はDropboxのリンクだけ書く
- 原作PDF、クライアント提供素材
- 未発売作品の筋書き（案件リポジトリ側に置く）
- **第三者が書いたプロンプトの原文**。他人の著作物はこのリポジトリに置かない（→ video-corpus）
