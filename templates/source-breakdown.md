# 原作の分解

**選ぶ前に、原作を選択可能な単位へ変える。**

> **この型は自社未検証。** 欄は**埋まらなければ消してよい。**
> ただし**「原作を引いたものは通り、引かなかったものは全部却下された」は自社検証**
> （→ `../principles/cross-media-style-translation.md`）。**分解する価値のほうは実証済み。**

**印象的な画を直接出す工程だけだと、記憶に残る場面へ候補が偏る。**
`../principles/workflow.md` の制約別20案は**発散として残す。台帳の代わりにはならない。**

## 単位を分ける

`source event` ／ `scene` ／ `beat` ／ `shot` ／ `cut` ／ `card` ／ `audio beat`。
**混ぜると、一場面から台詞だけ取って別の反応と組み直す判断が残らない。**

## 1単位あたりに書くもの

| 欄 | 中身 |
|---|---|
| **原作の位置** | 章・頁・コマ。**演出を書く前に全文検索で引く** |
| 出来事 | 何が起きるか |
| **知識の変化** | 誰が何を知る／知らないままか |
| 関係の変化 | |
| 台詞 | **文字数も数える**（→ 下） |
| 物・場所・音 | |
| **原作にあるか、推論か** | 混ぜない。推論なら承認対象 |
| spoiler | 答えか、問いの存在か |
| 権利 | 使用に制限があるか |

## 画面文字の量

**文字が絵に焼き込まれている素材では、カットの選定と同時に文字量の設計が発生する。**

1カットずつ数えて合計を先に出す。**通過するコマの文字は予算に入らない**
（→ `../principles/still-to-motion.md`）。

## 棄却したものを消さない

| 欄 | 中身 |
|---|---|
| 棄却した単位 | |
| **理由** | 重複／spoiler／虚偽の因果／訴求と不一致／生成費用 |
| 再利用の条件 | **別尺・別ターゲット・修正時に効く** |

## 集合として選ぶ

**個別に強い候補を上から採ると、同種の素材に偏る。**

1. **hard gate** — 権利／spoiler／虚偽の因果
2. **集合として**——主訴求の被覆／人物・物・場所・空白・文字の多様性／
   区間ごとの知識変化／**ショットサイズと運動量の反復**
   （→ `../principles/shot-structure.md`「カバレッジを表で見る」）
