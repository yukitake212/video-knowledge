# 撮影・演出の語彙表

## カメラ語彙

- 画の大きさ：WS（引き）／MCU（バストアップ）／CU（寄り）／インサート（差し込み）／マクロ（接写）
- カメラの動き：プッシュイン／オービット／トラッキング／ハンドヘルド／ウィップパン
- ピントと光：ラックフォーカス／ハイキー／タングステン／ブルーアワー
- つなぎ：ビート（1区切り6〜8秒目安）／マッチカット／パックヒーロー（締めの正面画）／ローワーサード

## アニメ演出の語彙（蓄積中）

- あおり = low angle looking up ／ 俯瞰 = high angle looking down
- なめ = 手前に何かを置いた構図 = foreground element framing the subject
- フレーム内フレーム = 戸口や柱の陰から覗く構図
- 逆光ハレーション／リムライト／ヴィネット（画面端の暗さ）

### 漫画記号

原稿を素材にするときに使う（→ principles/still-to-motion.md）。

- コマ枠 = panel border ／ frame ／ ページ = page
- 集中線 = speed lines ／ focus lines
- スクリーントーン = screentone ／ halftone dots
- 黒ベタ = solid black fill
- 吹き出し = speech balloon ／ speech bubble
- 擬音 = onomatopoeia ／ sound effect lettering ／ SFX text
- 断ち切り（コマが紙端まで達する） = bleed
- 線画 = line art ／ 主線 = key line

**記号は保持するだけでなく動かせる。** コマ枠をマスクやトランジションに、集中線を粒子に、
擬音を物理を持つタイポグラフィに、という使い方（2026-08 / 推測。未検証）。

## 大気・光の語彙

**変数の体系と使い方は `principles/atmospheric-fx.md`。ここは言い換えの対訳のみ。**

### 大気

- 霞 = haze ／ 霧 = fog ／ 靄 = mist ／ 粉塵 = dust ／ 煙 = smoke
- 体積を持った霧 = volumetric fog ／ 浮遊する微粒子 = suspended fine particles
- 地面を這う筋 = floor-hugging streaks ／ 巻き上がり = kick-up
- 後流（動く物の後ろに引く尾） = wake ／ trail
- 散逸（だんだん消える） = dissipation ／ 沈降 = settling
- 不均一な密度 = heterogeneous density ／ 局所的に濃い塊 = localized dense pockets
- 奥行き面ごとの分布 = through correct depth planes
- 突風 = gusting wind ／ 乱流 = turbulence

### 光

- 光線の筋（ゴッドレイ） = light shafts ／ god rays
  ※ 書くときは「散乱・遮蔽・影の体積」に分解する（→ atmospheric-fx.md）
- 逆光 = backlight ／ contre-jour ／ リムライト = rim light
- 跳ね返り = bounce ／ クロスライト = soft cross
- 頭上から落ちる光 = overhead fall ／ 劇中の実光源 = practicals
- 動機づけられた光源 = motivated source
- 接地影 = contact shadow ／ 大気遠近 = atmospheric depth haze
- 前方散乱 = forward scattering ／ 後方散乱 = backward scattering
  ※ 逆光の霧の見え方が変わるのはここ

### 光学効果

- 広角の遠近の誇張 = wide-angle perspective expansion
- 直線が直線のまま = rectilinear（魚眼にしない、の言い換え）
- 迫り出して見える = loom large
- 方向性のあるブレ = directional motion blur
- 行き過ぎて戻す修正 = over-correction
- ジンバルのように無菌ではない = never gimbal-sterile
- ドローンのように浮かない = never floaty drone
