# ショット記述の定型と作業文書テンプレ

## シネマティック実写マルチショットの型

Seedance 2向けの公開プロンプトを分解（2026-08 / corpus/sofa-scene, mecha-bug）。
全体スタイル→アセット台帳→ショットの3部構成で、**各ショットは同じ5見出しを毎回繰り返す。**
5見出しはそのままカット表の列にできる。

```
[templates/house-style-live-action.md を1回だけ貼る]

ASSETS
@ImageA = [名前] — [身長cm]、[髪]、[服を一点ずつ]、[消えない識別特徴（keep in every frame）]。
          Voice [声質・話し方]。参照が支配するのは顔の同一性のみ。
Locations: @ImageX (main face) と @ImageY (reverse face) — same room, opposite walls

FIRST FRAME (locked)
[開始構図を文章で固定。スタート画像が無いときの代替]

SHOT 1 — [サイズ] / (location @ImageX; off-centre; ONLY @ImageA in frame): [弧を矢印で1行]
LOCATION MAP  [誰がどこに、背後に何が、カメラはどちら側から]
FORMAT MODE   [One continuous take, ~Ns, real-time, no cut / Hard CUT from Shot N]
OPTICS        [レンズ・絞り・DoF]
CAMERA        [ハンドヘルド/固定・ドリフト・フォーカス]
ACTION TIMING 0–Ns: [誰が][どんな気分で]、セリフ「」。[瞬きと眉の指定]
              Physics: [重量・慣性・反動。nothing floats で締める]

NEGATIVE GUARDS
[肯定側で書いた各項目の失敗形を、末尾に一括で列挙]
```

### 文字カードのショット

テロップやタイトルカードも1つのショットとして表に載せる。映像カットと同じ行に並べ、
編集の最後に別工程で足すものとして扱わない（→ principles/typography.md）。

映像カットの5見出しに対して、文字カードは次の見出しを使う。

```
CARD n — [用途：フックのテロップ／転換／タイトルカード／CTA]
FORMAT        [尺とホールド秒数。静止画で作るか動画生成で作るか。
               前カットの切り方（ハードカット／ディゾルブ）と次カットの入り方]
COPY          [正確な文言。改行位置まで。約物と句読点も確定させる]
TYPOGRAPHY    [書体・ウェイト・字間・行間・揃え・サイズ階層。※固定アセットで作る]
FIELD         [何の上に置くか：純黒／木炭紙／霧／擦れた金属／煙／墨／ぼかした映像]
MOTION        [どう出て、どう止まり、どう消えるか]
TREATMENT     [ハレーション・グレイン・デフォーカスからの結像・粒子の通過・光線との干渉]
AUDIO CUE     [ヒット／ライザー／無音／BGMを抜くか]
```

- **COPY と TYPOGRAPHY は生成に投げない。** 日本語は字形・約物・字間の失敗コストが高いので、
  静止画または編集ソフト側で正確に作って参照アセットにする。生成側が担当するのは
  FIELD・MOTION・TREATMENT（→ principles/typography.md の「日本語の責任分配」）
- 映像カットの `OPTICS` に相当する欄は置かない。平面のグラフィックにレンズは無く、
  デフォーカスからの結像やボケは `TREATMENT` 側で書ける
- `AUDIO CUE` は音のトラック行と同じ場所に書く。画と音と文字を別々に決めない
  （→ principles/sound.md）
- 文字カードは**前後のカットの切り方とセットで決まる**。カード単体で成立を判断しない。
  `FORMAT` に前後の扱いを書くのはこのため

- 見出しを立てず一段落で書く場合でも、`BLOCKING:` `STATE LOCK:` `Optics:` `Physics:` `Lighting:` `Audio:` と大文字ラベルを文中に置けば構造は保てる
- ASSETS台帳にはそのショットに出る人物だけを載せる。出ない人物は台帳から外す

## 作業文書テンプレ（案件ヘッダ＋カット別）

プロンプトを使い捨てず版で管理する様式。**実際に生成に投げるのはカット別の FINAL PROMPT だけ。**

### 案件ヘッダ（1案件に1枚）

```
案件 / クライアント / 担当 / 発売日 / 納品形式（尺・アスペクト・本数）
ハウススタイルブロック：[どれを使うか。全文はここに1回だけ貼る]
禁則：[ネタバレ範囲・規制・クライアント指定のNG]
ASSETS台帳
  @人物名 = [身長cm/髪/服を一点ずつ/消えない識別特徴/声質]
           参照＝[ファイル名]。参照が支配するのは顔の同一性のみ。
           Standing note：[参照に写り込んだ不要物と、毎回のロック文]
           状態違い：[通常/汚れ/濡れ/負傷 などの別シートと、どのカットで使うか]
  @場所名 = [main face / reverse face の2枚。部屋のどの壁か]
  @文字アセット = [確定コピー/書体/字間/行分け/作成した静止画のファイル名]
                 どのカードで使うか。生成側に作らせない対象。
音声：[話者ごとのツール・声・設定値]
決定事項ログ：[日付｜決めたこと｜理由]
```

### カット別（各カットに1枚）

```
[案件名] WORKING PROMPT — CUT xx [カット名]
METADATA
  狙い：[このカットで何を伝えるか1文]
  尺／使い所：[完成尺での秒数と前後のカット]
  モデル・参照モード：[  ]
  UI側で設定する項目：[尺・アスペクト・参照モード等。本文には書かない]
  現在の版：v_ — [この版で狙ったこと]
FAILURE NOTES（内部用・本文には入れない）
  v_ defect：[出た不具合]  Fix：[直し方]
PATCH LOG
  [どのセクションをどう書き換えたか。他は変更なし]
工数
  生成回数：__ 回／所要：__ 分／採用テイク：__
FINAL PROMPT
  [上のショット記述の型]
```

- **状態違いは台帳側に持つ。** 汗・汚れ・濡れ・負傷を毎カットのプロンプトで書き直すと、
  カットごとに程度が変わる。同じ状態が3カット以上出るならシート化する
  （→ templates/character-sheet.md）
- **生成に渡す人物参照は文字なしの版にする。** 名前や身長を書き込んだ版は人が見る用で、
  参照に使うと画面への文字混入の要因になり得る（→ templates/character-sheet.md）
- **参照は「何を支配するか」を台帳に書く。** 参照素材は identity（人物）／set（室内・物理空間）／
  light motivation（外光・天候）／interaction object（操縦桿など触る物）／look（トーン全体）に
  役割が分かれる。同じ画像でも用途が違えば支配範囲が違う
  （→ principles/shot-structure.md の参照の扱い）
- 場所の参照は、その場所を画面に映すためだけでなく、**画面に映さずに光だけを持ち込む**
  用途にも使える。屋外が見えない室内カットでも、外の場所を light reference として渡すと
  光・色温度・天候・状況の連続が室内に入る
- **工数欄を必ず埋める。** どの工程に何分かかったかの数字がないと、切るべき案件の条件が決められない
- 決定事項ログは案件ヘッダ側に置く。カットをまたぐ判断（構成方針・話者・配色）はカット別の文書に散らさない
- FAILURE NOTES と PATCH LOG は生成には投げない
