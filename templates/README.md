# templates — 型と、貼るもの

**使い方が3種類ある。混ぜない。**

### 貼るもの — 一度書いて、以後そのまま

**判断が要らない。だから飛ばせない。**
実案件で一発で通ったものは、ほぼ全部がこの形だった。

| ファイル | 用途 |
|---|---|
| `lock-blocks.md` | **一度書いて以後そのまま貼るブロックの型。** 声のロック／参照のコネクタ／空白の禁止列挙／禁止／命名 |
| `house-style-live-action.md` | 実写ドラマ調のハウススタイルブロック。**貼るものの原型。** 素材が漫画原稿・イラストなら貼らない |

### 埋めるもの — 案件ごとに判断して書く

| ファイル | 用途 |
|---|---|
| `shot-ir.md` | ショット仕様。**モデルを決める前に埋める。** 中間表現 |
| `shot-schema.md` | ショット記述の定型と作業文書テンプレ。カット表がそのままプロンプトになる形 |
| `action-sequence-schema.md` | 身体的な負荷のあるアクション |
| `character-sheet.md` | キャラクターシート。連載・シリーズ案件の参照素材 |
| `asset-card.md` | 物・小道具 |

### 引くもの

| ファイル | 用途 |
|---|---|
| `vocabulary.md` | 撮影・演出の語彙表。カメラ用語とアニメ演出用語の対訳 |

**どれをいつ使うかは `../skill/SKILL.md`。**

**この区別が要る理由。** 「読んで判断するもの」は適用が毎回の判断なので**飛ばせる。**
実際、実案件で読み落としが繰り返し起きた。**「貼るもの」は飛ばすと出力が不完全になる。**
**知識を貼れる形へ移せるなら、そのほうが確実**（→ `lock-blocks.md`）。
