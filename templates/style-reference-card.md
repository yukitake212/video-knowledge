# 参照素材の権利カード

**本番のスタイル参照とカスタムモデルの学習に使う素材は、1点ずつこれを持つ。**

> **これは法的助言ではない。** 目的は、**制作工程で法務確認を可能にする情報を失わないこと**
> （→ `../OPERATIONS.md`「スタイル参照と学習素材の権利」）。
>
> **この型は自社未検証。ただし埋めて損はしない。**
> **抜けているほうが危険**——`permission_basis` が空のまま本番へ流れるのが最悪。

## 参照の分類

**6つのどれか。** external inspiration は**分析のみ。本番投入しない。**

| 種類 | 使い方 |
|---|---|
| owned canon | 権利者提供の設定・原画 |
| licensed | 許諾済みの第三者素材 |
| public-domain | 様式・時代の調査 |
| self-created | 社内で作ったもの |
| **external inspiration** | **分析のみ。特徴を抽象化してから使う** |
| anti-reference | 避ける方向の評価用。**negative prompt へ作品名を直送しない** |

## 出力側の記録

**生成物にも履歴を残す**（→ `../OPERATIONS.md` のリリース前チェック）。

参照した素材ID ／ ホスト・モデル・版・モード ／ job ID ／ 生成日時 ／
**人間が選択・修正したところ** ／ 承認者と承認版。

**job ID・プロンプト全文・生成物・契約IDは private 側。** public に置くのは型だけ。
