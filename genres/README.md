principles/ にあるのは原則として全ジャンル共通のもの。

**`templates/house-style-live-action.md` は移さない。** あれは

撮影監督ハンドルとRestraint節が刑事ドラマ寄りなのは、**実例だから**であって
混入ではない（2026-08-30 に判断を変えた）。

## 2軸で分ける

ジャンルの前に、上位の分岐が2つある。

|  | 実写調 | アニメ調 |
|---|---|---|
| **物語作品** | 刑事ドラマ、社会派人間ドラマ | 児童書ホラー など |
| **実用書** | （該当少ない） | 健康系実用書マンガ など |

- **物語作品か実用書か** — 前者は「続きが知りたい」で引き、後者は「自分の問題だ」で
  引く。構造が根本的に違う。実用書は予告というより広告に近い
- **実写調かアニメ調か** — 生成の作法がほぼ別物。実写用の知見（ポアレベルの肌、
  撮影監督ハンドル、35mmフィルムグレイン）はアニメ調では意味を持たない

**この2軸には「既知性への訴求」が入っていない。** 書籍なら著者・原作・シリーズ・前作。
引きの型を謎型か人物型かで決めるとき、**3つ目としてこれを並べる**。実際に案件のエンドカードは
「あの『◯◯』が、ついに漫画に。」という形を取っていたが、**設計としてではなかった**
（2026-08 / 自社検証・1案件。→ `principles/trailer-structure.md`）。

## 各ファイルに持たせる項目

比較できるように並びを揃える。

1. ハウススタイルブロック（撮影監督ハンドル／配色比率／Restraint節）
2. 骨格（30秒の並び）
3. 引きの型（謎型か人物型か、その理由）
4. 避けるもの（ジャンル特有の禁則、ネタバレの線引き）
5. 音の床（どの種類を使うか）
6. 参照素材の癖

## 置き場所の原則

ジャンル別ファイルは、1案件の実績を具体的に書くほど価値が出る。
一般化すると内容が消えるので、**genres/ の実体は video-projects（private）に置く**。
publicのここには枠と目次だけを残す。

## 素材を動かす知見はここではない

**素材を動かす知見は `principles/still-to-motion.md`。**
「原稿が漫画である」は作品のジャンルではなく素材の条件で、どのジャンルとも組み合わさる。
実用書マンガの案件は、`practical-manga.md` と `still-to-motion.md` の両方を読む。
