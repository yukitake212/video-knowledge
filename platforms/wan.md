# Wan 3.0

**未契約・未検証。** 2026-08-28 に、Alibaba のクリエイターマニュアルを紹介した記事から収集。
**原典は中国語で、こちらでは確認していない。**

現行の制作基盤は `platforms/magnific.md`。Magnific 経由で使えるかは未確認。

## 入力の上限

| 入力 | 上限 |
|---|---|
| プロンプト | 20,000文字 |
| first/last frame | **参照入力と排他**。フレームを渡すと参照が使えない |
| 参照画像 | 10 |
| 参照動画 | 5（合計15秒） |
| 参照音声 | 5（合計15秒） |
| 解像度 | 480p / 720p / 1080p |
| 尺 | 2〜30秒 |

**排他制約が最重要。** フレームを渡して動きを書くか、参照を渡して誰が何をするかを書くか、
**書き始める前に選ぶ。** 両方をやるプロンプトは存在しない。

参照の枠は**種類ごとに別**。合計20ではない。

## 6つの式

### 1. 基本

```
主体 ＋ 場面 ＋ 動き
```

「動き」には**静止も含まれる。** 動かないと宣言することも動きの指示で、Wan はそれに従う。

### 2. 上級

```
主体 ＋ 場面 ＋ 動き ＋ 美的制御 ＋ 様式化 ＋ 音
```

- **美的制御** — 光源、照明環境、ショットサイズ、視点、レンズ、カメラの動き。
  ここが曖昧だと安全な中景・平坦な光になる
- **様式化** — 視覚言語の名前。1〜2語で、前のほうに置く
- 主体・場面・動きにも**説明**が付く。場面の説明は**照明を決める**。
  表面と状態を名指しする（「ひび割れた橙色の土」「濡れた金属の手すり」）と
  光が反射する対象ができる。「農場」だけでは平坦な環境光が返る

**様式化は単語1つでは足りない。** 30秒もつのは、媒体（2Dアニメ／3D／シネマティックな長回し）と
光か色の規則（高コントラスト／ティール&オレンジ／冷たい白の月光を硬いキー）を**組にしたもの**。

### 3. フレームを渡すとき

```
動き ＋ カメラの動き
```

**それだけ。** 画像が主体も場面も様式も決めているので、書き直すと予算の無駄で、
指示の衝突源になる。

- 副詞で程度と速度を制御する（「素早く」「ゆっくり」）。
  **フレームが固定されているので、副詞が残された制御手段のほとんど**
- カメラを動かさないなら「固定ショット」と書く。**書かないことは固定の指示ではない**
- 様式は最後に一度だけ、**元フレームの見た目を保持せよという指示として**書く

**これは `principles/still-to-motion.md` と一致している。** 素材はショット設計済みの
アンカーなので、足す動きだけを書く。**外部の公式マニュアルが同じ結論に達している。**

### 4. 音

```
音 = 声 ＋ 効果音 ＋ BGM

声     = 「実際の台詞」＋ 感情 ＋ 抑揚 ＋ 速さ ＋ 声質 ＋ 訛り
効果音 = 音源の材質 ＋ 動作 ＋ 周囲の空間
BGM    = 曲そのもの ＋ ジャンル
```

**効果音の3スロットは「ドン」と書かせないためにある。** 材質を変えると同じ文が
別の音になる。材質を落とすと全部の平均が返る。

**BGM は場面に紐づける。** 単独で浮かせない。

音声ファイルを渡す場合は、音を説明するのではなく**画がどう応答するかの対応表**を書く。
強拍→この動き、静かな部分→この動き、サビ→密度を上げる。

### 5. 参照

```
@参照した素材 ＋ 動作 ＋ 台詞
```

- **同じ素材を、当てはまる箇所ごとに何度でも @ する。** 冒頭で1回宣言するのではなく、
  参加する全ての位置で再度指す
- **動作を書かないと、ポーズの周りで動くだけになる。** 参照画像はポーズであって演技ではない。
  動作の状態を名指しすることが、静止を演技に変える。「静止」も正当な答え
- 台詞は `{ }` で囲って地の文と分ける

### 6. マルチショット

```
全体の説明 ＋ ショット番号 ＋ タイムスタンプ ＋ ショットの中身
```

- **全体の説明**が、ショット7をショット1と同じ映画に保つ
- **ショット番号が構造の背骨。** 番号が無いと長いプロンプトが1つの続き物として読まれ、
  モデルがカットの位置を決めてしまう
- ワンテイクにしたいときは、**各ショットの冒頭に「カットしない」を毎回書く**

## 使い分け

1. 基本から始める。一行で足りているなら終わり
2. 出力に不満なところだけ上級のスロットを足す。
   平坦→美的制御、ありきたり→様式化、音が違う→音
3. **入力モードを書く前に選ぶ。** フレームか参照か。両方はできない
4. 中身に中盤があるならマルチショット
