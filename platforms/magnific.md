# Magnific（旧Freepik）

**現行の制作プラットフォーム（2026-08-25〜）。**
以下は 2026-08 に公式ドキュメント・製品ページで確認。**仕様は変わる。都度確認すること。**

## 基盤とモデル

- 単一モデルではなくマルチモデル基盤。Veo / Kling / Seedance / Wan / PixVerse / Runway / Hailuo / Sora / LTX を用途別に選ぶ。単一モデル障害への保険にもなる
- 尺はモデル依存でおおむね4〜15秒。Seedance 2.5は4〜30秒のネイティブ生成を謳う
- マルチショットは1生成で最大6ショット、各ショットに個別のプロンプトと尺を設定できる。対応はWan 2.5/2.6・Kling 3.0系・Seedance 1.5 Pro/2.0。Kling 3は合計15秒以内・各ショット3秒以上
- マルチショットは速いがトランジションをAIが決めるので制御が弱い。**精密な繋ぎや複数モデルの混在が要る本番はカット別生成＋Video Editorで合成**、が公式の使い分け

## 参照とキャラの一貫性

- 参照の渡し方：スタート画像のみ／スタート＋エンド画像（間の変化を生成）／PixVerse 5.5などは画像に直接描き込む Visual Prompt
- エンド画像指定はカットの着地点を固定できる。表情が変わりきる系のカットに効く
- キャラの一貫性はImage GeneratorでCustom Characterを学習させ、その画像をスタートフレームに使う。Custom Styleも同じ流れで画づくりを揃えられる
- HiggsfieldのCinema Studio・Cast・Soul ID・Lipsync StudioはHiggsfieldの機能でMagnificには無い。Magnific側の対応物はCustom CharacterとSpeak / Lip Sync

## 音声とリップシンク

- リップシンクは専用ツールが2つ：**Speak**（画像・動画から喋るクリップを新規生成、30以上の言語、最長5分）と、**Clip Editor内のLip Sync**（既存クリップの口を音声に合わせる）。動画モデル本体にリップシンクさせる必要はない
- 音声はVoice GeneratorがありElevenLabs v3を選べる。ボイスクローンは音声サンプル1〜5本から作成でき、2話者の掛け合いも1回で生成できる
- 音声生成のコツ（公式）：句読点で間を作る、全角大文字や変わった書式は避ける、読み間違いは表音表記で書き直す。クローン用サンプルは無音・無音楽で合計30秒以上、棒読みにしない
