# platforms — ホスト別の仕様

UI・上限・プロンプトの書き換え・契約・料金。**仕様は変わる。各項目に確認日が書いてある。**

ベースモデルの知識は `../models/`。同じモデルでもホストが変われば参照上限も入力種別も
書き換えも変わるので分けてある（分ける理由は `../models/README.md`）。

**`ホスト × ベースモデル × 版 × 生成モード` の4つが決まらないとプロンプトの形は決まらない。**

| ファイル | 状態 |
|---|---|
| `model-quirks.md` | **自社検証。このディレクトリで信頼度が一番高い。生成が壊れたらまずここ** |
| `magnific.md` | 現行の制作プラットフォーム |
| `higgsfield.md` | 公式情報が中心。自社未検証の項目が多い |
| `krea.md` | 2系統目の比較対象。未契約・未検証 |
| `candidates.md` | **分業先のツール候補。制作基盤の候補ではない** |

`model-quirks.md` だけ軸が違う。**モデル別でもホスト別でもなく、出所が自社検証であるという軸。**
