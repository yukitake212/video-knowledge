# Higgsfield Soul ファミリー（画像モデル）

**ホストとしての Higgsfield は `platforms/higgsfield.md`。** あちらは Cinema Studio・Edit・
契約・料金。ここは画像モデルとしての Soul。

**Higgsfield 専用。** 他のホストからは使えない。2026-08-28 確認 / 公式ヘルプセンター。
自社では未検証。

## 3つの別モデル

用途で使い分ける。

| モデル | 性格 |
|---|---|
| Soul | プリセット駆動。素早く出す |
| Soul 2.0 | ムードボード、参照画像、Soul HEX が使える。制御が一番広い |
| **Soul Cinema** | シネマ特化。**プリセットもムードボードも無く、映画的な質感がモデルに内蔵** |

**Soul Cinema は動画のキーフレーム用に公式が推奨している。** 接写・ムードのある場面・
質感・時代性に強いとされる。`principles/still-to-motion.md` の起点として候補になる。

## Soul ID — 実在人物の同一性

- 同一人物の写真**20枚以上、最大80枚**で学習
- 学習用の写真は、角度と表情に幅があり、よく照らされ、サングラス無し、濃い影無し、
  顔が切れていない、**全身が入ったものを最低1枚**、直近4〜5か月のもの、**本人の同意があるもの**
- 一度学習すれば **Soul ファミリー全体（Soul 2.0 と Soul Cinema）で使える**
- **Elements 経由で対応する外部モデルへも持ち込める**

### 単体ファイルとしてエクスポートできない

**これが一番重要な制約。**

したがって**正本は Soul ID ではなく、こちらが持つ顔のアセットのほうにする。**
Soul ID はそこから派生させたものとして扱う。

**Soul ID を正本にすると Higgsfield から出られなくなる。**
`principles/image-production.md` の「最終プロンプトは原本ではない」と同じ構造で、
**プラットフォーム固有の学習物を正本にしない。**

```
顔のアセット（正本。こちらが持つ）
  ├→ Soul ID（Higgsfield 用の派生）
  ├→ 他プラットフォームの同一性層（派生）
  └→ 参照画像として直接使う
```

### 公式内で食い違いがある

「Soul 2.0 で学習したキャラは Soul 2.0 でしか使えない」という記述と、
「Soul ファミリー全体で動く」という記述が**両方 higgsfield.ai 上にある。**
必要枚数も「5枚以上」と書かれた公式ブログがある。

**現行ヘルプセンター（20枚以上・ファミリー全体）を採るが、確定ではない。**
契約したら自分で確かめる。

## Soul Cast — 実在しない人物

ジャンル・予算・時代・アーキタイプ・アイデンティティ・容姿・細部（傷・刺青・そばかす）・
衣装の8カテゴリをパラメータ指定して、AI俳優を作る。プロンプト不要。
経歴付きのキャスティングシートが出る。ジャンルは14種。

「手に入りやすい顔ではなく、物語にちょうど良い顔を置く」ための設計。
**この考え方は他プラットフォームの画像生成プロンプトにも移植できる**
→ templates/character-sheet.md

**$5 の一度きりの支払いで、その顔を自分のアカウントに固定できる**（他者が使えなくなる、
商用権付き）とされる。**未確認。**

## Soul HEX — 色の制御

参照画像から主要な配色を抽出して、生成に適用する。Soul 2.0 と Soul Cinema で使える。
組み込みのパレットもある。

**既存の色比率70/20/10の運用と直結する**（→ principles/shot-structure.md）。
プロンプトで色を書くのではなく、**パレットを渡す経路がある**
（→ principles/prompt-compilation.md の分類B）。
