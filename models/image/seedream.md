# ByteDance Seedream 5.0 Pro（画像）

**動画の Seedance とは別のモデル。** 動画は `models/video/seedance.md`。

2026-08-28 確認。**ByteDance の原典は中国語で未確認。以下は二次資料。** 自社では未検証。

2026-06-23 の Volcano Engine FORCE で公開、2026-07-08 に一般提供。

## 仕様

- 出力は**最大2K相当（総画素 2048×2048 まで）**。プロンプトに解像度の語を書いても上限は上がらない
- **1リクエストにつき画像1枚**
- 参照画像 **1〜10枚**
- プロンプト上限は4000文字。**ただし ByteDance は600英単語以下を推奨。**
  超えると出力が劣化するか、細かい指示への追従が落ちる
- 出力は既定で PNG
- 対応言語は日本語を含む10言語以上。**言語によって建築・服装・顔立ちなどの文化的細部が変わる**

**600語の推奨が効く。** 動画側の「50参照は上限であって目標ではない」と同じ形で、
**上限と推奨が別**（→ principles/prompt-compilation.md）。

## 何が強いか

**精密な局所編集。** 座標・マスク・矩形・スケッチ・材質や色の指示で、
変える範囲を指定できる。テキストで場所を説明する必要がない
（→ principles/image-repair.md）。

**レイヤー分離。** 完成した画をレイヤーに分けられる。クリーンプレート作りに使える可能性がある。

**多画像の融合。** 複数の素材を1枚の整合した画にまとめる。

**編集専用のモデルが別にある。** 領域指定の修正とレイヤー分離は編集用、
新規生成は生成用と分かれている。**修正のときは編集用を選ぶ。**

## プロンプトの層

```
形式 → 被写体 → 構図 → 照明 → 画中の文字 → スタイル
```

各節を指示として読む作り。1枚の単純な画なら**30〜80語程度の絞ったブリーフ**、
情報の密なポスターや図版のときだけ長くする。

## 弱点（ByteDance 自身が認めているもの含む）

- **細かい文字の描画に改善の余地がある**とByteDance の公開情報が認めている。
  長い文章は崩れやすい
- 前バージョンより**肌が過度に滑らかになる**という報告
- 動的な場面で**動作が行き過ぎる**
- コンテンツフィルタの誤検知

**専用の否定プロンプト欄が無いホストがある。** その場合はプロンプト本文に除外を書く。
