# 芝居の演出指定

2026-08 にHiggsfieldの公開プロンプト（Seedance 2 / 2.5）を分解して抽出。出所は各項目の末尾。

## 目線

- 目線は方向ではなく**対象**で書く。画面外のものでもよく、それが視線の向きを固定する（「女の子たちのほうを見て（画面外）」「自分の正面をまっすぐ見る」）（corpus/sofa-scene, sofa-scene-2）
- 目線は**時間パターン**でも書ける。「前方の道路と後ろの負傷者のあいだで視線を往復させる」のように、往復そのものが葛藤を表す（corpus/backseat-bleeding）
- 目線は**注意の状態**として書くのが最も自然。「女の子たちのほうは見ず、ストレッチに没入している」。眼球の位置ではなく、何に気を取られているかを書く（corpus/sofa-scene-2）

## 話し方

- 声は2層で管理する。ASSETS台帳に恒久的な声質（音域・話し方の癖）、各ショットにその場の言い方（「好奇心まじりに、急かすように」「したり顔で誇らしげに」）（corpus/sofa-scene）
- セリフは ACTION TIMING の時間帯に置き、直後に気分を短く添える（「乗り気で、少し急いている」程度の一言）。Audio節では声の聞こえ方を別に書く（「低く途切れがちな涙声の慰め」）（corpus/sofa-scene, backseat-bleeding）
- 台帳に身長をcmで書く。同一フレーム内の人物の相対スケールが固定される（corpus/sofa-scene）
- 音声指定は**内容・声色・禁止事項の3点セット**で書く。順序は、非言語音（息、笑い）→
  台詞の正確な文言 → 言い方 → リップシンクの指定 → 出してはいけないもの
  （2026-08 corpus/mech-cockpit-dyad）
- **短い台詞は一文だけのほうが安定する可能性がある。** 観察した例の発話は
  「ありがとう」の一言だけで、関係性は周辺行動（息切れ・目が合う・軽い笑い）が担っていた。
  長い会話で感情を説明せず、**言語情報を減らして関係性は周辺行動で補う**
  （2026-08 corpus/mech-cockpit-dyad。安定性は未検証）

## 表情

- 表情は**類義語3つで三角測量**する。恥じらい・幼さ・おかしみ、と近い意味の語を重ねて一点に絞り込んでいる例があった。1語だと解釈幅が広すぎ、多すぎると散る（2026-08 corpus/sofa-scene-2）
- 表情は**内的な原因**で定義すると外さない（「何も聞こえなかったかのような、少し戸惑った表情」）（corpus/sofa-scene-2）
- 感情はラベルではなく**身体症状と、こらえている努力**で書く（涙が今にも溢れる／顔がくしゃりと歪む／顎が震える／かろうじて保っている）（corpus/backseat-bleeding）

## 肌のリアリズム

`photorealistic` と書くだけでは人肌の説得力は出ない。**独立したブロックとして管理する**
（2026-08 corpus/mech-cockpit-dyad）。

観察した例が列挙していたもの：

- 毛穴が見える
- 産毛
- 皮下の透過（subsurface）
- 左右非対称
- 眼に本物のキャッチライト
- ほつれ毛
- 肌はマットで、光沢を持たない
- 蝋のよう／プラスチック／エアブラシ／CG／人形、ではない
- 自然な瞬き
- 額と眉の微細表情が生きている

人間らしさは **皮膚・眼・髪・顔の微動** の4要素で作られていると整理できる。
既存の「顔を死なせないための能動指定」（瞬き・眉の微細表情）はこの4要素目にあたる。
残りの3つを足す。

**二人以上が同じフレームに入るときは、全員に同じ指定をかける。**
片方だけ指定すると、片方だけCGっぽくなる可能性がある。

## 動きと「生きている下限」

- **顔を死なせないための能動指定**：瞬きを常時入れる、額と眉の微細表情を動かす、mask-face と dead eyes を禁じる。静止させるために瞬きや表情を止めると、AIっぽい死んだ顔になる（corpus/sofa-scene ほか全プロンプト共通）
- 何もしていないカットにも「生きている下限」を書く。呼吸・瞬き・小さな自然な動き（corpus/sofa-scene-2）
- 動きは**環境に起こさせる**。段差の衝撃、ハンドル修正、風。人物が自発的に動かなくても画が生きる（corpus/backseat-bleeding）
- 人物Aが人物Bを動かす形で書ける（「近づいて、そっと前に倒してストレッチさせる」）。芝居の連鎖になる（corpus/sofa-scene）
- 間違ったポーズを先回りして名指しで打ち消す（「頭は下げるのではなく、横に傾ける」）。動きの幅も限定する（「ふつうのストレッチ。アクロバットはしない」）（corpus/sofa-scene-2）
- モデルが取りがちな**隣接解釈**を名指しで潰す：「SLOW PUSH-IN (dolly), not slow-mo」「calm, low-key — NOT a dramatic reveal」（corpus/sofa-scene-2）

## 努力と負荷

物理的にきつい行為は、動詞だけでは伝わらない。**行為と、それがどれだけ苦しいかを
別のレイヤーで指定する。**

観察した例では `climb` という動詞とは独立に、「かろうじて登る（確定）」というブロックが
立っていて、腕が震える／掴みが滑る／踏ん張っている／疲弊している／**簡単ではない**、が
まとめられていた（2026-08 corpus/zephyr-cliffhang）。

分解すると4つ。

| 層 | 例 |
|---|---|
| 行為 | 登る |
| 難易度 | かろうじて／簡単ではない |
| 身体症状 | 腕が震える／掴みが滑る／踏ん張る |
| 感情のトーン | 疲弊 |

既存の「感情はラベルではなく身体症状とこらえている努力で書く」の延長だが、ここでは
人物の感情ではなく**物理行為の難易度を制御している**点が違う。

### 部位の指定は力点の可視化に使う

身体の部位をフレームに入れる指定は、**どこに負荷がかかっているかを見せるため**に使える。

観察した例では、胸・背中・腰／尻・ブーツ・膝、という部位が指定され、同時に
「完全に着衣」「アスレチックに」「品よく」「裸体なし」「性的な行為なし」「露骨な描写なし」
という柵が張られていた（2026-08 corpus/zephyr-cliffhang）。

部位と力学の対応：

- 手 → 掴む力（grip）
- 背中 → 踏ん張り（strain）
- 腰 → 引き上げ（haul）
- ブーツ → 接地・滑り止め（traction）
- 膝 → 進んだこと（progress）

つまり **exertion visibility / leverage visibility / contact visibility** の3観点で
部位を選ぶ。エロティックなフレーミングとしてではなく、力学の可視化として設計する。
柵は同時に張ること（→ principles/guards.md）。

## 二人芝居

### 5層で動かす

良い二人芝居は次の5層が同時に動いている（2026-08 corpus/mech-cockpit-dyad）。

| 層 | 内容 | 観察例 |
|---|---|---|
| task | 何をしているか | 操縦桿を操作している |
| state | 身体状態 | 息が上がっている／汚れている／眼鏡がズレている |
| micro-behavior | 視線・瞬き | 周囲を見る／瞬きする |
| social beat | 相手との接続 | 目が合う／軽く笑う |
| line delivery | 台詞 | 「ありがとう」 |

**どれか一つでも欠けると、二人が同じ画面にいるだけになる。**

### 一発ショットの構造：state → relation → release

観察した一発ショットは、状況が見える → 空間の狭さが分かる → 二人の役割差が分かる →
疲労が見える → 関係性が進む → 一言で締まる、という順で組まれていた
（2026-08 corpus/mech-cockpit-dyad）。

抽象化すると、

- **state** — 息切れ・狭さ・操縦中
- **relation** — 目が合う
- **release** — 共有される笑い＋一言

**関係を説明する台詞を書かず、状態と接続と解放で見せる。**

### 近さは距離ではなく圧迫構造で書く

「二人が近い」では足りない。誰が下で誰が上か、どこに圧迫があるか、どんな不自然さや
苦しさか、まで書く（2026-08 corpus/mech-cockpit-dyad）。

観察した例の書き方は、相手の上に／覆いかぶさる形で押し込まれている、
最大限に不自然でねじれた姿勢、空間が極端に狭い、身体が強く押しつけられている、
というもの。

さらに順番が効いている。**親密さより先に、狭い・不自然・ねじれている・息が上がっている、
を置いてから目を合わせて笑わせている。** 感情の親密さを、空間の不快さの上に載せる。

### 役割差は身体の使い方に落とす

性格ラベルで二人を分けても、画では差が出ない。**四肢の仕事・占めている空間・疲れ方・
姿勢の質**に落とす（2026-08 corpus/mech-cockpit-dyad）。

観察例：

| | 操縦している側 | 押し込まれている側 |
|---|---|---|
| 四肢の仕事 | 両手が操縦桿、足はペダル | 支えるだけ |
| 占める空間 | 座席側・下 | 上から入り込む |
| 疲れ方 | 息が上がる、周囲を見る | 胸が上下する、汚れている |
| 姿勢の質 | 操作の姿勢 | ねじれた不自然な姿勢 |

### 二人の顔には同じ光条件を明示する

シーン全体の照明とは別に、**両者の顔に同じ光が当たっていることを書く**。
「両方の顔に硬い影が落ちる」「両方とも顔の半分が影」のように、
`BOTH` を明示する（2026-08 corpus/mech-cockpit-dyad）。

これを書かないと、片方だけ明るい／片方だけ別ライティング／片方だけ肌質が違う、
という崩れが出る可能性がある。

### 身体接触は状況由来にする

接触のあるシーンは、語彙をロマンチックな側ではなく物理的・実務的な側に寄せる。
観察例の語彙は、狭い・不自然・ねじれた・荒い呼吸・埃っぽい・コックピットの唸り・
革の軋み（2026-08 corpus/mech-cockpit-dyad）。

**空間の狭さ・疲労・汚れ・操縦中というタスク**を強く置くと、接触が状況から生じたものに
なる。音声側の柵も同時に張る（→ principles/guards.md）。

## 構図とブロッキング

- 構図は毎ショット「off-centre, never centred」と書く。これだけでドキュメンタリー的な生っぽさが出る（corpus/sofa-scene, sofa-scene-2）
- **狭い室内でも off-centre は有効。** タイトな3/4のクローズアップでも中央に寄せず、
  片側に余白（negative space）を作る。ドキュメンタリー的な生っぽさに加えて、
  片側の圧迫と片側の逃げ場という構造が生まれる（2026-08 corpus/mech-cockpit-dyad）
- BLOCKING を独立ラベルで書き、幾何と、**その幾何が動作を強制する理由**まで書く（「真後ろに座っている。斜めではない。だから運転手は自分の肩越しに手を回すしかない」）（corpus/backseat-bleeding）
- ショットごとに「ONLY @ImageA in frame」と登場人物を制限する。人数は数で固定する（「車内にいるのは正確に2人」と数で明示する）（corpus/sofa-scene-2, backseat-bleeding）
- **生成が苦手なものは構図で画面外に出す。** 人はそこにいる設定のまま、オーバーザショルダーと背景の完全ボケで写さない。同時に「空のソファを見せるな」と失敗の形を名指しする（corpus/sofa-scene-2）
- 背景を読めなくするのはコスト削減の技でもある。ボケて判別不能なら破綻しようがない。LOCATION MAPとOPTICSの2箇所で「unreadable, no sharp furniture, creamy bokeh」と念を押す（corpus/sofa-scene-2）
