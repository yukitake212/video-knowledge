# principles — モデル非依存の原則

どのプラットフォームでも効く書き方の芯。

**どれをいつ読むかは `../skill/SKILL.md` が決める。ここは一覧。**
17ファイル・約3000行あるので、頭から読む用途では作られていない。

| ファイル | 何が書いてあるか |
|---|---|
| `workflow.md` | 発想と制作の工程。**プロンプトを書く前に読む** |
| `prompt-compilation.md` | プロンプトを組み立てる工程。情報の4分類、削る順序、出所の格付け |
| `shot-structure.md` | ショット構造の原則。参照の役割分担、物理、編集文法の固定 |
| `guards.md` | 破綻を潰す書き方。否定の使い方、世界の複製、破局の増幅 |
| `directing.md` | 芝居の演出指定。目線、表情、二人芝居、切り出された台詞の演技 |
| `still-to-motion.md` | **静止画素材を動かす。** 漫画原稿・書影・挿絵。読字予算、網点、clean plate |
| `image-production.md` | 画像制作の工程 |
| `image-repair.md` | 画像の修正。**生成とは規律が違う** |
| `world-assets.md` | 世界と場所のアセット |
| `atmospheric-fx.md` | 大気・光・粒子・影 |
| `typography.md` | 文字の設計。テロップ、タイトルカード、モーションタイポグラフィ |
| `sound.md` | 音の設計。床、ヒット、無音、声 |
| `shot-recipes.md` | **目的別のレシピ辞書。**「この見え方を出すには何と何を同時に置くか」。全件が外部情報・自社未検証 |
| `vertical.md` | 縦型（9:16）の構図と解像度 |
| `trailer-structure.md` | 予告編の構成と編集。訴求の三分類、知識曲線、ショット間の関係。**ほぼ全部が外部情報** |
| `book-trailer.md` | **未映像化書籍**の表象設計。完成映画の予告とは素材条件が違う。**外部情報** |
| `visual-style.md` | **作品の視覚・時間スタイル。** 8つの層、12軸、媒体モード。**アニメと実写の分解はここ。外部情報** |
| `cross-media-style-translation.md` | 原作から動画への翻訳。preserve / translate / invent / omit。**外部情報。資料が薄い** |

## 読むときの注意

各項目に**出所と時期**が書いてある。自社検証か、他人のプロンプトの分解（`corpus/xxx`）か、
外部情報か、推測か。**割り引き方は `../skill/SKILL.md` の「出所で割り引いて読む」。**

ジャンル固有の内容が混ざっていたら `../genres/` へ移す（→ `../CLAUDE.md`）。
