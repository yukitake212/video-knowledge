# 世界と場所のアセット

出所と時期を各項目に書くこと。2026-08に収集。**大半が未検証。**

**30秒単発の案件では `templates/shot-schema.md` の「main / reverse の2枚」で足りる。**
以下は、同じ場所が何度も出る案件・連作・シリーズで効く。過剰に作らない。

## 階層

```
世界の設定
  ↓
場所のマスター
  ↓
空間の見取り図
  ↓
アングル別の見え方
  ↓
状態違い（時間帯・天候・破壊後）
  ↓
ショットのフレーム
```

**上から順に確定させる。** キャラクターシートの Identity → Body → Wardrobe → State と
同じ構造で、**上が動くと下が全部やり直しになる**（→ templates/character-sheet.md）。

## 世界の設定

案件をまたいで変わらないもの。

- 時代・地域・技術水準
- 素材の語彙（何でできている世界か。木と紙か、コンクリートと蛍光灯か）
- 色の方針（→ principles/shot-structure.md の70/20/10）
- 光の性格（どういう光が支配的か）
- 禁則（この世界に存在しないもの）

**連作でなければ作らない。** 単発案件ではハウススタイルブロックが同じ役割を果たす
（→ templates/house-style-live-action.md）。

## 場所のマスター

その場所が何であるかを固定する1枚。

- 空間の種類と規模
- 主要な材質と、その状態（新しいか、傷んでいるか）
- 目印になるもの（**これが一番効く**）
- 基準となる光

**目印を決める。** 「同じ部屋だ」と読ませるのは、壁の色ではなく、そこにある特定の物。
既存の「消えない識別特徴を1つ決める」の場所版
（→ templates/character-sheet.md）。

## 空間の見取り図

**画像ではなく文字で持つ。** どこに何があり、どの壁とどの壁が向き合っているか。

これが無いと、アングルを変えたときに**別の部屋になる**。既存の「世界の複製を止める」
（→ principles/guards.md）は、これが無いから起きる。

## アングル別の見え方

main / reverse は最低限。同じ場所を3カット以上使うなら、使うアングルの分だけ持つ。

**別アングルを生成するとき、見取り図と目印を両方渡す。** どちらか片方だと、
似ているが別の場所が出る。

## 状態違い

同じ場所の、時間帯・天候・破壊前後。

**光は場所の属性ではなく、独立した状態として持つ。** 同じ部屋の昼と夜を
「別の場所」として管理すると、目印の一貫性が崩れる。**場所は1つ、状態は複数。**

キャラクターの state sheet と同じ考え方で、**同じ状態が3カット以上出るなら
アセット化したほうが安い**（→ templates/character-sheet.md）。

## 作る枚数の目安

既存の「案件開始時に作るアセットは30秒15カットで7枚程度」を超えない
（→ principles/shot-structure.md）。

**階層を全部作るのは、その投資が回収できる案件だけ。**
判断基準は物アセットと同じで、**2回以上登場するか、意味を担うか**
（→ templates/asset-card.md）。
