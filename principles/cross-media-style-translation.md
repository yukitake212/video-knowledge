# 原作から動画へのスタイル翻訳

**適応は、物語内容を別媒体へ移すだけではない。** 漫画・挿絵・小説が情報を与え、隠し、
時間を作り、感情を外在化する**方法そのもの**を、動画の別の資源へ移す作業。

## この領域は資料が薄い

**調査の114件のうち、漫画・適応・媒体文法の資料は9件しかない**
（アニメ制作工程28件、生成AI製品27件、実写撮影20件、生成・評価研究20件、権利10件に対して）。
**しかもその9件のうち複数に「全文アクセス差あり」「書籍アクセス制限」「学位論文」という
限界が付いている。**

**事業の観点では、ここが未映像化書籍の案件で実際に使う部分**であって、
アニメ制作工程の28件より優先度が高いはずの領域。**その裏づけが一番薄い。**

以下の**翻訳表の個々の対応は統合推論であって、実証されたものではない。**
出所は他のLLM（Codex / GPT-5系）の文献調査で、**自社での検証はゼロ**
（原文は `video-corpus/research/visual-style-2026-08-30/`）。

## 4分類で記録する

各特徴について、必ずどれかに割り当てる。

| 処理 | 定義 | 例 |
|---|---|---|
| **preserve** | 同じ媒体要素として保持 | 原作の線画をそのまま動かす |
| **translate** | 別の映像・音響要素へ機能を移す | 擬音の圧力をインパクトフレーム＋音へ |
| **invent** | 原作にないが媒体成立に必要 | 小説から照明の動機を設計する |
| **omit** | 意図的に捨てる | 長い説明を予告編では落とす |

**受け入れる損失と、その補償を併記する。「何も失っていない」と書くのは避ける。**
媒体が変われば必ず何かが変わる。

`principles/still-to-motion.md` の「原作からの距離を3段階で決める」を置き換えない。
**距離は全体方針、4分類は特徴ごとの台帳。**

## 原作タイプ別

### 小説

**小説に画がないのではない。** 視点、語彙密度、比喩、反復、知識制限、文の速度、余白がある。

| 原作の証拠 | 何を抽出するか | 映像での翻訳候補 |
|---|---|---|
| 視点の制限 | 誰が何を知らないか | 見せない画角、被写界深度、遮蔽物 |
| 文の長短 | 心理・行動の時間密度 | ショット尺、カット率、運動密度 |
| 反復する語 | 作品のモチーフ | 色・形・音・インサートの反復 |
| 比喩 | 感覚の関係 | 光・材質・音・動きへの非直訳 |
| 省略 | 空白と謎 | 画面外、音橋、黒、反応カット |
| 語りの距離 | 親密か客観か | レンズ距離、カメラの介入度、音声設計 |

**「時代・場所・人物」を画にするだけでは一般的な映画になる。** 作品固有性は、
**何を見せないか／どの感覚を反復するか／誰の知覚に閉じるか**から出る。

### 漫画

**原作性は単独コマの絵柄だけでなく、コマ連鎖とページ構成にある。**

抽出対象——コマの機能、ページめくり前後の情報制御、コマサイズと時間知覚、
枠内と枠外、断ち切り、余白、視点間の距離変化、外在的な空間カット、
擬音・速度線・漫符、静止像の中の運動方向、反復構図と決めゴマ。

**コマを順番にパンするだけが翻訳ではない。**

| 漫画側の機能 | 動画での候補 |
|---|---|
| 大ゴマで時間を止める | 長いホールド、音を先に進める、微小運動だけ残す |
| 細かい連続コマ | カットの連射、スタッカートな音、部分アニメーション |
| コマ外の出来事 | 画面外の音、反応、遮蔽、カットアウェイ |
| 擬音 | 文字保持／音／画面振動／形の変形の組み合わせ |
| 集中線 | 背景運動、光、被写体との速度差、グラフィックの重ね |
| ページめくりの驚き | カードや黒で情報を遮断してから開示 |
| 複数コマの同時比較 | 分割、マッチカット、モンタージュ、反復音 |

**この対応表が一番、裏づけの薄い部分。** 使うときは案件で確かめる。

### 挿絵・装画

**装画は販売面の顔で、本文世界の平均的な場面とは限らない。** 4つに分けて読む。

- **canon evidence** — 人物・服・物の事実
- **look evidence** — 線・色・材質
- **marketing evidence** — 一目で認知させる構図とモチーフ
- **exceptional art** — 表紙だけの特殊処理

**表紙一枚から全編の時間文法を推定しない。** 時間の情報が無いなら
**「発明」と明記して、複数案を比較する。**

## 筋を進めないカットの機能

`principles/trailer-structure.md`「物語を進めないカット」の分類を、翻訳の側から細かくしたもの。
**削除候補にする前に、どれを担っているか判定する。**

| 種類 | 機能 | 予告編での使い方 |
|---|---|---|
| 空間インサート | 空間・方角・距離を置く | 短尺でも世界の実在感を作る |
| 物のインサート | 物を物語の担い手にする | 謎、伏線、商品認知 |
| 大気の枕 | 情報密度を落として呼吸を作る | 台詞や衝撃の前後に余韻 |
| 主観の転位 | 人物の感情を環境へ移す | 顔を説明しすぎない |
| 象徴のカットアウェイ | テーマ・比喩を置く | 直接説明を避ける |
| 反応の不在 | 反応を見せず欠如を強調 | 不安、冷酷さ、断絶 |
| リズムの句読点 | 音楽・編集の句を区切る | モンタージュの拍節 |
| **媒体の記憶** | 原作媒体の構文を残す | 漫画的な外在カットなど |
| 誤誘導 | 故意に観客を迷わせる | ミステリ。**誤認の回収が要る** |
| テクスチャ | 表面・天候・時間を感じさせる | 作品の物質感を固定 |

**「筋に不要」と「機能がない」は同じではない。** ただし30秒では全部は残せないので、
**各インサートがどの機能を担い、他の音・画・文字で代替できないか**を記録する。

`principles/trailer-structure.md` の「構成パターンに属さないシーンは残さない」を
否定するものではない。**インサートが空間・主観・リズムの機能を持つなら、
そのパターンに属しうる**、という追加。

## 二重の文脈

原作から切り出した画や台詞は、**原作内の文脈と予告編内の文脈を同時に持つ。**

- 原作でのスタイル状態と、原作内での物語機能
- 予告編で新たに担う機能
- 前後カット・音とのリズム
- 既読か未読か、媒体への期待

**原作の場面が静かでも、予告編では加速区間に置かれることがある。**
色や台詞の演技を原作どおり固定するだけでなく、**どの軸を原作保持し、どの軸を予告編機能へ
合わせるか**を明示する（→ `principles/directing.md`「本編どおりの演技を再現すればよいわけではない」。
**あちらは音、こちらは画。同じ構造**）。

## 翻訳レビューの質問

1. 原作でこの特徴は**何の機能**を持つか
2. 対象媒体に**同じ機能を担う資源**はあるか
3. **表面をコピーして機能を失っていないか**
4. 機能を移しても原作の識別性は残るか
5. **発明した部分を原作由来と誤記していないか**
6. 予告編内の新しい意味が、原作を不当に歪めないか
7. **権利者が承認すべき判断点はどこか**
