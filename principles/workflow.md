# 発想と制作の工程

出所と時期を各項目に書くこと。

## なぜ工程を分けるか

- 工程は think → set up → generate → test の4段。「散らかった着想をショットディレクションに翻訳する」ことを**独立した工程**として扱い、名前を付けて切り離している（2026-08 Higgsfield Academy）
- Higgsfieldは生成の前段に「cinematic logic layer」を置き、LLMに物語の弧・ペース・カメラ論理・視覚的な強調点を先に組み立てさせている。人は「ドラマチックにして」としか言わないので、**意図を具体的な映像計画に展開する工程を分離する**のが設計思想（2026-08 Higgsfield公式）
- **着想と制御を同じ一手でやろうとすると、制御が発想を食う。** 破綻しない案を1つ出してそれを守る側に回ってしまい、撮りたいものが一行も書かれないまま進む（自社の失敗）
- 創作のアイデア自体は短い一文でよい。長大な技術記述は制御のためのもので、着想とは別レイヤー。両者を混ぜない（2026-08 Higgsfield公式）
- 難しいのは一発の良いカットではなく、複数カットにまたがる一貫性（キャラ・場所・カメラ言語・スタイル）（2026-08 Higgsfield公式）
- プロンプトはキャプションではなく**脚本のト書き**として書く（2026-08 Higgsfield公式）
- 失敗テイクを読むことが独立した技能として教えられている（Read your failed takes）。失敗を禁止条項で潰すのではなく、モデルの傾向を読む材料にする（2026-08 Higgsfield Academy）

## 制作フロー

> **注意：このフローは未検証。** 2026-08時点で、この順序で1案件を通したことはない。
> 業界標準と他社の実績値から組んだ仮説であり、実際に回してから見直すこと。
> 現行の進め方との差分は OPERATIONS.md の「クライアント承認の設計」を参照。

1. **Think** — 原作から画だけを抜く。実現可能性もネタバレ判定も一旦外して、視覚的に強い具体物と状況を20個ほど列挙する。そのうえで、この映像が何なのかを一行で決める。**プロンプトの話は一切しない**
2. **試し撮り** — 軸に沿って3〜5カットだけ生成する。強度を測るのが目的で、完成品は作らない
3. **構成提出** — 試し撮りの結果を根拠に構成を出す。カット表とセリフを添えてここで確定させる
4. **本生成** — 作業文書テンプレでカットごとに版管理。工数を記録する
5. **編集・提出**

## 一発で作らず、段階に分ける

同じ責任分担の考え方が、複数の工程で繰り返し現れる（2026-08 整理）。

| 対象 | 先に確定させるもの | 後から足すもの |
|---|---|---|
| キャラクター | 顔（identity） | 体格 → 衣装 → 状態違い（→ templates/character-sheet.md） |
| 文字カード | コピーと字組 | 背景・光・粒子・モーション（→ principles/typography.md） |
| ショット | 参照アセット | 構図とカメラはプロンプト側（→ principles/shot-structure.md） |
| 長いアクション | 中間安定姿勢での分割点 | 各区間の芝居（→ templates/action-sequence-schema.md） |

**共通しているのは、動かない側を先に固定して、動く側を後から乗せること。**
逆順にすると、動きを作り直すたびに同一性がやり直しになる。

上流固定の数字上の裏付けは OPERATIONS.md にある（固定すれば1ショット3生成、
固定しなければ8〜10生成に膨れる）。

## 編集の5つの破綻と、その処方

制作のボトルネックは生成から編集に移っている。「AI生成は編集の複雑さを減らさなかった。
むしろ増やした」「美しいAI生成ショットは映画ではない。素材だ」「プロンプトは選択肢を
作る。編集が物語を作る」（2026-08 AI映像制作の実務記事）。

複数の場面を繋いだときに出る破綻は5つ。**うち4つは上流か一括処理で消える。**

| 破綻 | 処方 | どこで直すか |
|---|---|---|
| トーンの漂流 | 全体に1つのグレードをかける。カットごとに調整しない | 一括処理・5分 |
| 地理の不明瞭さ | 場所アセットを main face / reverse face の2枚で持つ | 上流のみ |
| 感情の進行の崩壊 | 骨格を型として持つ | 上流のみ |
| 連続性の切断 | 30秒を通して切れない音を1本敷く（→ sound.md） | 一括処理・安い |
| ペース | 各カットの尺と切りどころ。**唯一の個別判断** | 編集 |

**残るペースだけが個別判断で、しかもリズムの型は持てる。** 雛形の秒数から始めて
微調整する形にすれば作業量は大きく減る。

**止まりを残すこと自体がペースの設計になる場合がある。** 静止画を素材にするティザーでは、
全カットを常時動かすのではなく、静止・微動・完全な動きを使い分け、重要な台詞や反応の
前後に止まりを残す方法がある。漫画は読者がタイミングを制御する媒体なので、
映像化すると制御が制作側に移る。その差を止まりで埋める
（2026-08 / 外部の実務記事。elser.ai、2026-08-05。自社未検証）。

## AIスロップは工程の失敗

「AIスロップはモデルの失敗ではなく工程の失敗から生まれる。凡庸なブリーフは、モデルの
品質にかかわらず凡庸な結果を保証する」。技術的には破綻していないのに交換可能で凡庸、
という状態が主要な失敗モード。

1万投稿の調査では、AI支援コンテンツは純人間製を31%上回ったが、**その上昇分は
レビューして磨いたものから来ていて、生の出力からではなかった。**

配信面のリスクも実在する。TikTokとMetaでは、AIと判定されたコンテンツが人間製より
大幅に配信を絞られる。YouTubeも同様の傾向。**納品物がSNSで回る以上、営業上も無視
できない。**

## 順序についての教訓（自社）

- **確定文書を出すタイミングを後ろにずらす。** 素材を一枚も見ないうちに構成候補群を出すと、生成してみて前提が崩れる。実際に、山場として想定していたアクション寄りのカットが期待ほどの迫力を持たず、静かな儀式的カットのほうが予想以上に強くなり、提出済みの構成が全面的に変わった
- **発散は案件の頭で行う。** 制作の途中でやると最も高くつく。ある案件では、軸となる構成方針にたどり着いたのが作業10時間目だった
- 原作は「規則の source」ではなく「画の source」として読む。何がネタバレかを確認する読み方だけでは、強い画は出てこない

## Think工程でやること

### 制約を課して並列に出す

「いくつか案を出す」では5個で止まり、そこまでは誰でも思いつく範囲になる。
**制約パターンごとに20案ずつ、評価抜きで出す。**

制約は、その案件の既定値を壊す方向に選ぶ。実写ドラマ調の既定値は「スーツの人が
喋っている画」なので、それを禁じる制約が効く。

常備の制約セット：

- 人の顔を一切使わない
- 物しか映さない（人が写らない）
- すべて俯瞰
- 全部マクロ
- 手だけで語る
- 不在だけを撮る（本来あるべきものが無い状態）
- 同じ構図の前後2枚だけで作る
- 一つの場所だけで完結させる
- 物の視点から撮る
- 文字を一切使わない
- 一人の顔だけで30秒
- 天候と光だけで語る

**制約ごとに出力を分ける。** 混ぜると平均化される。「制約Aで20、制約Bで20」と
分けて指示すること。240案出れば200個は捨てるが、残りは既定値の外にある。

### 謎型か人物型かを最初に決める

好奇心には最適な情報量がある（情報ギャップ理論）。知識ゼロでは好奇心は起きず、
全部知ってもいなくなる。**中間で最大になる。**

短い尺では、引きの型は2つのうちどちらかしか選べない。

**謎型** — 視聴者が自分で考え始める仕掛けを置く。ただし**視聴者が参加できる謎**で
なければならない。手がかりのない謎は「眺めるだけの謎」になる。
「なぜ解けないのか」は参加できない。「逃走中の人間が、なぜ武器を手放したのか」は
視聴者も「たしかに変だ」と考えられるので参加できる。

**人物型** — 一人の人生を凝縮して情を移す。パズルではなく人で引く。

**ジャンルで決めない。** ミステリーでも、犯人が先に分かる構造なら読者が追っているのは
謎ではなく人なので、人物型のほうが原作に忠実になることがある（自社の反省）。

### 発想を出させる指示のしかた（Claudeに対して）

生成と評価を同じ一手でやると、実現可能性のフィルタを通した後の1案しか出てこない。
以下を明示すると発想が出る。

- **「評価するな、20個出せ」と数を指定する**
- **「使えないものも混ぜろ」と明示する。** 実現不可能を許可するとフィルタが下がる
- **「場面」ではなく「一枚の画」を要求する。** 場面は要約、画は具体。
  「葬儀のシーン」ではなく「白い菊の海を真上から見た、その中央に一枚の遺影」
- **恣意的な制約を与える。** 自由だと既定値に落ちる
- **「読者が覚えているのは何か」と訊く。** あらすじではなく残像を訊かれると、
  画の側から考え始める

## 文字作品から画を見つける手

小説の世界は視覚的に貧しいことが多い（事務所、会議、会話）。原作にある場面を
そのまま並べると、スーツの人が喋っている画ばかりになる。

実際にうまくいったカットは、**原作に「場面」として書かれていないもの**ばかりだった。
潰された監視カメラ、刻印を削られた小道具、雨の路面、人の消えた路上。
どれも「証拠がない」という抽象を物に落としたもの。原作は「証拠がない」と
書いているだけで、その画は書いていない（自社検証）。

- **不在を撮る。** 無いものは有るものより撮りやすい。空の路上、外されたブラケット、
  削られた刻印
- **スケールを飛ばす。** 同じ対象をマクロと俯瞰で撮ると、平凡な物が映画になる
- **時間をずらして同じ枠を撮る。** 人で埋まった通りと、翌日の無人の通り。
  同じ構図の2枚が時間の経過を語る
- **視点を人間から外す。** 床に落ちた小道具から、ロッカーの中の瓶から、レンズから
- **二つの意味が重なる一枚を探す。** 弔う側の列の中に、その死の原因を作った人物が
  立っている。画は一つなのに意味が二重になる
- **音を画にする。** 警報の瞬間に鳩が飛び立つ

## 冒頭3秒の設計

ショート動画のリテンション研究から（2026-08収集）。

- 判断が起きるのは**2〜3秒**、あるいは「最初の12フレーム」＝24fpsなら0.5秒
- ある調査ではショート動画の平均リテンションは**1.5秒付近**
- 構造は**フック0〜3秒、約束3〜5秒、本編、締め**
- フックは3層の合わせ技：**最初のフレーム・テロップ・音**が同時に働く
- 最初のフレームのチェックリスト：**被写体が画面を埋めている／文字のコントラスト比
  4.5:1以上／主要な物か動作が動いている**
- **「動きのない静止したショットは低エネルギーとして読まれる」。** 推奨は
  **動きの途中から始めること**——既に何かをしている人にカットで入る、リビールの
  途中から始める、結果を先に見せる

  これはショット単位でも同じ。短尺のショットでは**導入をショットの外で済ませる**。
  「第1フレームで既に事態が始まっている。空の状況説明フレームを置かない」と明示する
  （2026-08 corpus/creature-charge。→ principles/shot-structure.md）。
- 離脱の崖は**5〜8秒**。「フックは決まったのに中盤が平坦で、説明はするが展開しない」
  状態がそこで起きる

### 静止から始めてよい場合

上の原則には例外がある。**静止していること自体が意味を持つ場合**。

漫画原稿を素材にするティザーでは、冒頭を完全に静止した原稿として見せ、遅れて瞬き・視線・
コマ枠の突破を発生させる構成が考えられる。「静止した媒体だと思ったものが生命を持つ」という
**認知の差そのものをフックにする**（2026-08 / 推測。視聴データによる検証なし）。

**ただし自社の失敗例と構造が同じである点に注意。** 冒頭を静止した被写体へのゆっくりした
プッシュインにして、平均再生8秒・スキップ38.6%だった。この2つの違いは、
静止の後に何が起きるかだけ。

**静止から始めるなら、次の3つを守る。**

1. **動き出す瞬間を冒頭3秒以内に置く。** 離脱の崖は5〜8秒なので、それより前に払う
2. **音を消していても0.5秒以内に何かが読める。** 静止画＋無音＋文字なしは情報がゼロ
3. **動き出しが「ようやく動いた」ではなく「動くはずのないものが動いた」と読める形にする。**
   単なる遅れたプッシュインは、意味のない静止と区別できない

3つを満たせないなら、既定どおり動きから始める。

### 取る原則と捨てる原則

文献の推奨には「最初の2〜3ショットは0.4〜1.2秒の極小カット」「無音の間を作るな」も
含まれるが、**これをやると落ち着いたトーンが壊れる。** チュートリアル動画と文芸作品の
予告は同じ土俵ではない。

**取る**：最初のフレームに動きがあること／文字を早く出すこと（音を消していても
0.5秒以内に何かが読める）／5〜8秒ごとに何かが変わること／約束は1つに絞ること

**捨てる**：極小カットの連打／無音の排除／パターン割り込み

### 自社の失敗例

冒頭を静止した被写体へのゆっくりしたプッシュインにした。被写体が写真なので**静止画の中の
静止画**で、これ以上動きの少ない画は作れない。テロップが出るのは2.0秒で、音を消して
いる人には2秒間なにも情報が届いていなかった。前作のインサイト（平均再生8秒・
スキップ38.6%）は、文献にある5〜8秒の離脱の崖と一致する。
