# 作品の視覚・時間スタイル

**「アニメ調」「実写調」「レトロ」「この作家っぽい」を、制作可能・比較可能な仕様へ分解する。**

このファイルの出所は**他のLLM（Codex / GPT-5系）の文献調査**で、**自社での運用検証はゼロ。**
こちらで一次情報に当たり直したものは節ごとに書いてある。原文は

## なぜ絵柄の一覧では足りないか

生成サービスのアニメ分類には、**同じ階層に別種のものが並んでいる。**
少年・少女は市場と語りの系統、chibi は形態、retro / modern は時代、cel / painterly は表面処理、
sakuga は運動と作画密度。**これをそのまま社内分類にすると、たとえば「retro」を色褪せだけで
再現して、当時の構図・作画密度・撮影・音を落とす。**

**完成像は、各工程の規則が収束した結果**であって、単一の「絵柄モデル」から出てこない。
アニメ制作は色彩設計・色指定・仕上げ・撮影を別職能に分けており、
海外の長編アニメ制作も visual development / look development / layout / animation / lighting を
分業している（外部情報。制作会社の公式工程説明。**自社未検証**）。

## 8つの層を混ぜない

| 層 | 問うこと | 混ぜると起きること |
|---|---|---|
| **物語ジャンル** | 何を感じさせる作品か | 絵柄名だけで構成まで決める |
| **媒体モード** | 何として見せるか | 技法と媒体の制約を誤る |
| **歴史・系譜** | どの時代・地域・制作文化に接続するか | 時代を色味だけで模倣する |
| **造形言語** | 形をどう抽象化するか | 顔だけ合わせて背景が別作品になる |
| **撮影言語** | 空間・光・レンズをどう組むか | LUTだけで映画らしさを作ろうとする |
| **時間言語** | 動きをどう刻むか | 高fps化で原作のリズムを消す |
| **表面・合成** | 最終像をどう物質化するか | 表面プリセットを作品スタイルと誤認 |
| **固有影響** | 誰・何との類似を狙うか | 権利・誤認・模倣リスクを見落とす |

**`genres/README.md` の2軸を置き換えるものではない。** ジャンルは訴求と構成、
こちらは**それをどの視覚・時間文法で知覚させるか**を担当する。

## 記述する12軸

**A. 物語上の視覚機能** — 誰の知覚として画面を設計するか／観客に約束する感情／
世界と人物を何で対立させるか／何を見せ何を隠すか／予告編で担う機能。

**色やレンズ値は出発点ではなく、機能の結果として持つ。**

**B. 造形** — シルエットの傾向／頭身・誇張／記号化の度合い／曲線と直線／
**変形予算**（表情とアクションでどこまで形を壊せるか）。

**アニメではキャラ・背景・小物・エフェクトが同じ抽象度にいる必要はない。ただし差は意図でなければならない。**

**C. 線** — 輪郭の有無・太さ・均一か可変か・色／内側の線の密度／エッジの質（鋭い・柔らかい・
途切れる・震える）／記号（集中線・漫符・速度線）／**感情や運動で線が変形するか**。

**D. 色** — 基準色と禁色／明度域と黒レベル／彩度方針／人物基準色／
**シーン変体**（昼・夕・夜・屋内外・記憶・危機）／全体を通した色の変化／
何だけ高彩度にするか／どこでパレットを切り替えるか。

**一色のLUTではなく、基準＋局所変化という構造で持つ。**

**E. 光** — 光源の物語上の理由／方向と比率／硬さ／減衰とネガティブフィル／実光源／
露出方針／ハイライトの落ち／**影の設計**（セルの段数か、写実の連続階調か、色つき影か）／大気。

**F. 材質・表面** — 表面モデル／テクスチャの粒度／紙目・フィルム質感／粒状感／ハレーション／
ゲートウィーブ／色収差／合成のエッジ。

**「フィルム風」を一属性に畳まない。** ARRI の Film Lab は
**grain / color / halation / gate weave を独立した4つの設定として持つ**
（2026-08-30 / 一次情報で確認。ARRI公式。grain は 50D / 200T / 500T 相当、
halation は明部の赤橙のにじみ、gate weave はフィルム特有の微細な不安定さ）。

**G. 空間** — アスペクト比／奥行きモデル（平面・層状・深い遠近）／配置／余白／
地平と消失点／前景の遮蔽／スケールの手がかり／構図の偏り。

**H. 光学・カメラ** — カメラの存在感（不可視・観察者・主観・身体的）／フォーマットの印象／
レンズ系／焦点距離のふるまい／被写界深度／フレアとボケ／高さと距離／移動の型と抑制。

**数値だけでは足りない。** レンズは肌・ボケ・フレア・空間圧縮・観客との距離を変える。
アニメでも仮想カメラ、作画パース、マルチプレーン、平面パンが同じ機能を持つ。

**I. 運動設計** — 運動密度／ポーズの強さ／予備動作／間隔と弧／誇張／スミア／
インパクトフレーム／副次運動／カメラと被写体の結合／エフェクトの運動。

**「sakuga」を画風名にしない。** 見せ場でのポーズ、タイミング、線と形の変形、
エフェクト、カメラとの結合として記述する。

**J. 時間文法** — 基本のコマ打ち（1コマ・2コマ・3コマ・混在・実写の連続運動）／止めの方針／
段階的か滑らかか／間の長さ／時間の非対称／ランプ／編集と音との関係／
**意図した時間の手触り**（安定・手描きの揺らぎ・意図的なつっかえ）。

**ここが一番効く。→ 下の「時間にも絵柄がある」**

**K. 編集・音との結合** — ショット尺の分布／カットの動機／不連続の方針／
インサートの種類／トランジション／音橋／画と音の同期か対位か／文字カードとの関係。

**L. 一貫性と変奏** — 全編で変えない不変条件／章・世界・時代で変える変数／
一カットだけ許す逸脱／感情の頂点で意図的に壊すもの／**無意識の漂流**／許容誤差。

**一貫性は「全部同じ」ではない。不変部分と、意味を持つ変化が区別されている状態。**

## 時間にも絵柄がある

**アニメのスタイルは静止フレームだけでなく、どこを動かさず、いつ密度を上げ、
どの瞬間に形を壊すかに宿る。**

**limited animation は低品質の同義語ではない。** 止め、部分運動、選択的な描画枚数、
急な作画密度の上昇は、予算制約に由来する場合があっても、**長年の使用で知覚・感情・リズムの
文法になっている**（2026-08-30 / 一次情報で確認。Sheuo Hui Gan "Motion and Emotion in Anime",
*The Cambridge Companion to Manga and Anime*, Jaqueline Berndt 編, 2024。
**抄録は「感情を引き出す運動は抽象化・誇張・様式化された形に依存し、表現のしかた自体が
注目の中心になる」としている。** 全文は未読）。

**したがって、生成AIで常時24fps相当の滑らかな補間をかけると、技術的には連続していても
媒体忠実度が下がる。** 「smooth」「cinematic motion」は既定の品質語になりやすいが、
原作が強い静止・部分運動・間欠的なポーズ・インパクトフレームを使うなら、**滑らかさは損失。**

**指定すべきは fps ではない。**

- どの動作を何コマ保持するか
- どの部位だけ動くか
- 静止を破る瞬間はどこか
- 見せ場で作画密度をどこまで上げるか
- 形の崩しを許すのは何フレームか
- 背景・カメラ・エフェクトのどれが運動を担うか

これは `principles/still-to-motion.md` の「止まりを残す」と同じ話を、
**作品全体の時間文法へ昇格させたもの。**

## 実写側

**実写では「絵柄」ではなく look / visual language / cinematography と呼ぶが、体系はある。**
そして **LUT だけではない。**

```
脚本・主観 → 美術・衣装・場所 → レンズ・カメラ・照明 → 露出・記録媒体 → VFX・現像・グレード
```

**最終色だけを模倣しても、撮影上の因果は戻らない。** 上の F 軸に書いたとおり、
ARRI は grain / color / halation / gate weave を別制御にしている。
ACES は show LUT と shot 単位の調整を分けて工程間で受け渡す（外部情報。**未検証**）。

`templates/house-style-live-action.md` は**この12軸を1つ埋めた実例**として読む。
**普遍的な分類ではなく、現代ドラマの抑制系という1プリセット。**

### 実写化で保持するのはピクセルではなく関係

漫画のベタ影を実写の顔へそのまま塗る必要はない。**保存候補は関係のほう。**

- 主人公だけ背景から分離する明度・色の関係
- 狭い余白で圧迫する構図
- 世界は直線、人物は曲線という形態対比
- 見せ場直前の長い止まり
- 顔を見せず手や物で感情を示す情報政策
- 一見無関係な環境カットで主観を外在化する編集

**この関係を、実写では美術・衣装・ブロッキング・レンズ・照明・音・編集へ割り振る。**

**表面記号だけを移すとコスプレ感が出る。** 漫画・アニメの誇張を実写へ持ち込んだ制作事例は、
単一のフィルタではなく**深度・彩度・パイプライン・線・合成・顔の表現まで制作系を変えた**と
説明している（外部情報。**未検証**）。

## 同じ意図を、媒体別に実装する

| 意図 | アニメでの実装例 | 実写での実装例 |
|---|---|---|
| 孤立 | 低密度の背景、人物だけ暖色、静止 | ネガティブフィル、長焦点の圧縮、環境音を薄くする |
| 世界の過剰 | 形の変形、色面、速度線、インパクトフレーム | 広角の近接、深い焦点、色彩美術、身体的なカメラ |
| 記憶 | 線・塗り・コマ打ちを変える | フォーマット・レンズ・質感・露出・音場を変える |
| 不安 | 崩れる寸前の顔、間欠運動、空間インサート | 負の余白、固定の長回し、光源外の暗部、非同期の音 |
| 親密 | 線と背景の情報量を落とす | 近い距離、肌の質感、浅い呼吸音、穏やかな支持機材 |

**（統合推論。外部資料からの整理であって、実証されたものではない）**

## 媒体モードを2〜4案作る

**「アニメか実写か」を最初に二択で決めない。** 原作の識別的な文法を抽出してから、
**各文法を最も損失少なく実装できるモード**を選ぶ。

| モード | 強み | 危険 | 向く条件 |
|---|---|---|---|
| source-motion | 原作素材の認知と信頼を最大化 | 無理な立体化、文字・網点の破綻 | 原作画が強く、短尺で既知性を使う |
| 2D limited | 止め・選択的運動・記号を保持 | **生成系が勝手に滑らかにする** | 漫画的な時間や省略が核心 |
| 2D full / high-motion | 強いアクション、変形 | キャラと線の漂流 | 運動そのものが訴求 |
| 2.5D / マルチプレーン | 原画保持と奥行きの両立 | 紙芝居感、レイヤー破綻 | 挿絵・漫画を空間化したい |
| stylized 3D | カメラの自由度、資産の再利用 | 造形がゲーム・玩具化 | 世界探索、複雑なカメラ |
| 実写・抑制 | 身体、物質、社会的な現実感 | 原作記号の消失 | 人間ドラマ、現実への接続 |
| 実写・誇張 | 漫画的な誇張を物理世界へ | **コスプレ感、均質なCG感** | 原作の過剰さ自体が価値 |
| hybrid | 媒体差を表現に使う | ルールなしの混在 | 世界・時間・主観の境界がテーマ |

`source-motion` が現行の主戦場（→ `principles/still-to-motion.md`）。
**あちらは素材の保持を扱い、こちらは媒体モードの選択を扱う。**

## 原作から抽出する

### 1点から一般化しない

**表紙・決めゴマ・宣材は強いが、作品全体の平均ではない。**
平常・転調・見せ場、昼夜、人物・世界・物を横断して証拠を取る。採用は3つで判定する。

- **反復するか**（原作内で繰り返し出るか）
- **機能があるか**（物語・人物・世界の機能を持つか）
- **識別力があるか**（なくすとその作品らしさが大きく減るか）

**3つとも弱い特徴は、偶然か単発の装飾として入れない。**

### 観測・解釈・翻訳を分ける

| 種類 | 書き方 |
|---|---|
| **観測** | 「夜景では寒色の背景に暖色の顔が反復する」 |
| **解釈** | 「孤立した人物を世界から分離している可能性」 |
| **翻訳提案** | 「実写では背景を低彩度、顔の実光源だけ暖色にする」 |

**この3つを一文に畳むと、後でどこから直すべきか分からなくなる。**
権利者が解釈だけ修正でき、モデルを変えても観測は残る。

`principles/directing.md` の「Quoted fact / Derived state / Creative direction」と同じ規律。
**あちらは台詞の演技、こちらは画。**

### anti-reference を持つ

「こうしたい」だけでなく、**近いが違う例**を記録する。「高彩度だがポップではない」
「線は粗いが未完成には見せない」「実写的だが広告的な美肌にはしない」。

**ただしモデルへの長い negative prompt に直送しない**（→ `principles/guards.md`
「禁止の範囲を広げすぎると必要な動きを巻き添えにする」）。まず評価基準として使う。

## 三段階で持つ

```
案件全体のスタイル
  └─ シークエンス変体（章・世界・時間帯・感情段階）
       └─ ショット例外（一カットだけの理由ある逸脱）
```

- **下位は差分だけ持つ**
- 下位が上位を上書きするなら、**理由と、いつ戻すかを必ず書く**
- **同一性・権利条件・禁則は、ショット側で勝手に上書きできない**
- 「見せ場だから全部変える」は不可。**変える軸を列挙する**

ショット側に足すのは5行だけ（→ `templates/shot-ir.md`）。**全体仕様をショットに複製しない。**

## 検証したいこと

1. **同一原作で、一語のスタイルラベル／この仕様／仕様＋参照の役割分離**の3条件を比較する
2. **source-motion / 2D limited / 2.5D / 実写翻訳**を同じ場面で作り、
   **「どれが美しいか」ではなく「原作のどの機能を保存し、何を失い、何で補償したか」**で比べる
3. **滑らかな運動 vs 止め・コマ打ち・インパクトフレームの明示。**
   意図した止まりが保たれるか、微動が勝手に足されるか
4. 共通のテストセット（人物単体／会話の寄り／2ショット／広い環境／昼夜のペア／
   高速運動／止め／物のインサート／文字との共存／3ショットの連続）を1組固定する

**この検証が終わるまで、どのプラットフォーム・プリセット・参照方式が優れるかを断定しない。**
